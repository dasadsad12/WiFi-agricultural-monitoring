# WiFi 农业服务器部署

本项目使用独立云服务分区，默认端口为 `18127/TCP`、服务目录为 `/opt/wifi-env-agri`、数据目录为 `/var/lib/wifi-env-agri`，systemd 服务名为 `wifi-env-agri-relay.service`。

先从 Windows 上传压缩包：

```powershell
scp "wifi-agriculture-v1.zip" root@YOUR_SERVER_IP:/www/
```

登录服务器后，把下面四个值替换为新生成且互不相同的令牌，再执行：

```bash
set -Eeuo pipefail
ZIP=/www/wifi-agriculture-v1.zip
INSTALL=/opt/wifi-env-agri
SERVICE=wifi-env-agri-relay.service
DEVICE_TOKEN='替换为新的农业设备令牌'
ADMIN_TOKEN='替换为新的农业管理令牌'

test -f "$ZIP"
getent group lora-env-ops >/dev/null 2>&1 || groupadd --system lora-env-ops
id loraenv >/dev/null 2>&1 || useradd --system --gid lora-env-ops --home-dir /nonexistent --shell /sbin/nologin loraenv
install -d -o root -g lora-env-ops -m 0750 "$INSTALL"
install -d -o root -g root -m 0750 /etc/wifi-env-agri
install -d -o loraenv -g lora-env-ops -m 0750 /var/lib/wifi-env-agri
python3 -m zipfile -e "$ZIP" "$INSTALL"
cat > /etc/wifi-env-agri/wifi-agri.env <<EOF
WIFI_AGRI_HOST=0.0.0.0
WIFI_AGRI_PORT=18127
WIFI_AGRI_DEVICE_ID=WIFI_AGRI_001
WIFI_AGRI_DEVICE_TOKEN=$DEVICE_TOKEN
WIFI_AGRI_ADMIN_TOKEN=$ADMIN_TOKEN
WIFI_AGRI_DATA_DIR=/var/lib/wifi-env-agri
WIFI_AGRI_WEB_ROOT=/opt/wifi-env-agri/web
WIFI_AGRI_ONLINE_TIMEOUT_MS=10000
EOF
chmod 600 /etc/wifi-env-agri/wifi-agri.env
install -m 0644 "$INSTALL/systemd/wifi-env-agri-relay.service" /etc/systemd/system/
install -m 0644 "$INSTALL/systemd/wifi-env-agri-history-cleanup.service" /etc/systemd/system/
install -m 0644 "$INSTALL/systemd/wifi-env-agri-history-cleanup.timer" /etc/systemd/system/
chown -R root:lora-env-ops "$INSTALL"
chmod -R u=rwX,g=rX,o= "$INSTALL"
systemctl daemon-reload
systemctl enable --now "$SERVICE" wifi-env-agri-history-cleanup.timer
firewall-cmd --permanent --add-port=18127/tcp
firewall-cmd --reload
sleep 2
systemctl --no-pager -l status "$SERVICE"
curl -fsS http://127.0.0.1:18127/health
```

云平台安全组还需要放行入方向 TCP `18127`。前端 `js/config.js` 的管理令牌需填写同一个 `ADMIN_TOKEN`。
